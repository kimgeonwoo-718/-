# 띄어쓰기 시험지

띄어쓰기를 건드리는 고침이 **이득인지 손해인지** 재는 데 쓴다.
`tools/localcheck/measure-spacing.sh` 가 이 두 파일을 읽는다.

| 파일 | 무엇 | 좋은 결과 |
|---|---|---|
| `keep.txt` | **붙여 쓰는 것이 맞는** 긴 낱말이 든 문장 (기관명·법령명 따위) | 손대는 수가 **적을수록** |
| `split.txt` | 붙여 써서 들어온 글 | 손대는 수가 **많을수록** |

## 왜 필요한가

띄어쓰기는 한쪽을 얻으면 다른 쪽을 잃는다. `CorrectionEngine.GLUED_RUN_SYLLABLES` 를
8에서 7로 내려 보면 되살림이 19→20으로 하나 느는 대신 오교정이 6→9로 셋 는다.
**숫자 없이 고치면 좋아진 줄 알고 나빠진다.**

## 한계

50문장뿐이다. 예전에 쓰던 3,000문장 말뭉치는 저장소에 없다(스크래치패드에서 재고 버렸다).
이건 **회귀를 잡는 그물**이지 정확도를 재는 자가 아니다. 큰 변화를 다룰 때는 말뭉치를
제대로 구해서 재라.

문장을 더 넣어도 된다. 다만 `keep.txt` 에는 **정말로 붙여 쓰는 것이 맞는** 것만 넣어라 —
틀린 기대값이 들어가면 이 시험지가 거짓말을 하기 시작한다.

## 지금 손대는 것 (2026-09-19 기준 9/30)

`keep.txt` 에 **둘 다 맞는** 것이 섞여 있다. 전문 용어와 기관 이름은 한글 맞춤법 제50항이
**단어별로 띄어 씀을 원칙으로 하되 붙여 쓸 수 있다**고 한다. 그래서 아래 여섯은 갈라도
틀린 것이 아니다 — 숫자만 보고 "나빠졌다" 고 읽지 마라.

    소비자 물가지수가 · 고속도로 휴게소에서 · 정보 통신기술자
    한국어 능력시험을 · 국제 축구연맹이 · 국세청 홈택스에서

**진짜 틀린 것은 셋뿐이고, 셋 다 끊는 자리가 틀렸다.** 이게 남은 숙제다.

    근로기준법시행령이 → 근로 기준 법시 행령이   ('법시'·'행령'은 낱말이 아니다)
    부동산실거래가신고를 → 부동산 실 거래가 신고를
    사회복지사자격증을 → 사회 복지 사 자격증을   ('사'가 떨어져 나왔다)

형태소 사전이 긴 덩어리를 나눌 때 나는 오류다. 나누기를 넓히거나 좁히는 것으로는
안 고쳐진다 — 끊는 자리 자체를 고쳐야 한다.
